Политика конфиденциальности Brain

Действует с 22 октября 2026 года.

Кто пользуется

Brain — личный Telegram-ассистент одного владельца. Им пользуется только владелец, сторонние пользователи к нему не подключаются.

Какие данные Google используются

  • Google Календарь: список календарей и события, чтобы показывать расписание, напоминать о встречах, создавать, менять и удалять события по просьбе владельца.
  • Gmail: чтение писем, чтобы показывать владельцу его почту, и отправка писем по его просьбе.

Любое изменение (событие, письмо) выполняется только после явного подтверждения владельцем.

Где хранятся данные

Ключи доступа к Google хранятся на личном сервере владельца в закрытом виде. Письма и события не сохраняются в отдельной базе, а запрашиваются у Google в момент обращения. Ассистент хранит только историю разговора с владельцем, и не дольше 14 дней.

Кому передаются

Данные не продаются, не используются для рекламы и не передаются третьим лицам. Для ответа на запрос владельца текст запроса и нужные для ответа данные обрабатываются ИИ-сервисами: Anthropic (Claude) и, для голосовых сообщений, OpenAI (распознавание речи).

Использование информации, полученной через Google API, соответствует Google API Services User Data Policy, включая требования Limited Use.

Как отозвать доступ

Доступ можно отозвать в любой момент на странице myaccount.google.com/permissions.

Summary (English)

Brain is a private assistant used by a single owner. It reads the owner's Google Calendar and Gmail to answer the owner's requests and creates events or sends email only after the owner confirms each action. Google data is not sold, not used for advertising and not shared with third parties; it is processed by AI providers (Anthropic, OpenAI) only to answer the owner's requests. Use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. Access can be revoked at any time at myaccount.google.com/permissions.
